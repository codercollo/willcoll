D. RULES THE STRUCTURE ENFORCES
================================================================================
  - internal/shared imports no product or platform package (depguard +
    test). internal/platform imports shared only. Products import shared
    and platform read helpers, never each other.
  - One sqlc package per database; a query for one database cannot
    compile against another's tables.
  - Each frontend app talks only to platform-api and its own product API.
  - A product app owns no sign-in, account, billing or admin page: a
    signed-out visit goes to platform's /auth/login?return_to=<page>, and
    return_to is honoured only for origins in runtimeConfig.public.apps
    (utils/appLinks safeReturnTo). One session cookie serves every app
    (host-only on localhost in dev; Domain=SESSION_COOKIE_DOMAIN in
    production).
  - A change under internal/shared or frontend/layers/base triggers the
    tests (and deploys) of every service that depends on it.
